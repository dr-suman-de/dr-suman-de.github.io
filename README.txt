Dr. Suman De — Personal Professional Profile Site
https://your-speaker.github.io

Executive Split design — custom single-page portfolio for Dr. Suman De,
Head of Research & Industry-Academia Partnerships at SAP Labs India.

Sections:
    About · Career Timeline · Research & Publications · Speaking · Education &
    Skills · Certifications · Achievements · Contact

Built with Bootstrap 4, jQuery, Isotope, Playfair Display + Inter (Google Fonts),
and Themify Icons. All custom styles are in a <style> block inside index.html.
No build step required — open index.html directly in a browser.

Assets used:

    Icons:
        Themify Icons:          (https://themify.me/themify-icons)

    Fonts:
        Google Fonts:           (https://fonts.google.com)
            Playfair Display    — headings
            Inter               — body and UI text

    Libraries (local, in assets/vendors/):
        jQuery:                 (https://www.jquery.com)
        Bootstrap 4:            (https://getbootstrap.com)
        Isotope:                (https://isotope.metafizzy.co)
        Themify Icons CSS:      (https://themify.me/themify-icons)

SEO:
    Canonical URL, Open Graph, Twitter Card, JSON-LD Person schema (Schema.org),
    Google Search Console verification, sitemap.xml, robots.txt.

Files:
    index.html      — entire site (HTML + custom CSS + content)
    sitemap.xml     — XML sitemap for search engine crawlers
    robots.txt      — crawler directives pointing to sitemap
    SETUP.md        — guide for replicating this site for a new profile
    assets/imgs/    — profile photo (avatar.jpg)
    assets/css/     — johndoe.css (base template, unmodified)
    assets/vendors/ — local copies of Bootstrap, jQuery, Isotope, Themify Icons
